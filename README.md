Bumrah Style Bowling Machine-

An interactive project inspired by the unique bowling action and delivery style of Indian fast bowler Jasprit Bumrah.

This project explores the concept of a cricket bowling machine designed around Bumrah-inspired bowling mechanics, with an interactive interface for exploring and configuring the build.

 Project Overview-

The Bumrah-Style Bowling Machine is a personal engineering project focused on exploring the design and concept of a bowling machine inspired by one of cricket's most distinctive bowling styles.

The project aims to combine mechanical engineering concepts, automation, and interactive visualization to explore how a bowling machine could reproduce different bowling characteristics.

 Project Objectives-

Explore the engineering concept of a cricket bowling machine.

Develop a Bumrah-inspired bowling machine design.

Explore mechanical and automation aspects of bowling delivery.

Create an interactive interface to present the project concept.


 Run Locally-

Clone the repository:

git clone https://github.com/Mukul09819052023/bumrah-bowling-machine.git

Navigate to the project directory:

cd bumrah-bowling-machine

Open index.html in your web browser.

No additional installation is required for a standalone HTML implementation.
